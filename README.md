## V2.9：整个词库的看图理解

- 全部 **49,426** 个词条接入同一个图文入口；这不是每个词都已经有正确图片的承诺。
- 新增 **85** 组经过逐张检查、对应明确词义的 Commons 图片，附中文画面说明、作者及许可，本地图片共约 5.49 MB；首次按需加载，查看后缓存，也可随完整离线资料一起下载。已有 andiron 使用示意图继续保留。
- 基于现有 WordNet 具体事物类别，为 **9,774** 个词提供可自动寻找的图片主题候选。进入阅读视野时才联网，不在每次键入时请求；用户选择主题后才确认为图文，不自动采用搜索第一项。抽象词及其他词可主动查找场景或概念图。
- 具体配图标注对应义项，例如 apple（水果）、dog（动物）、table（桌子）。图片可点击放大，保留来源；放大框支持键盘关闭。
- 在“我的”中可关闭自动查图。搜索词会发送至 Wikimedia API，不上传收藏、复习和阅读记录。此前版本“仅点击才联网”只适用于历史版本；本版自动模式依此说明。
- 故障时保留词义、例句和来源链接，没有图片不伪造。新图片模块不改变搜索输入法修复、收藏、复习安排或四卡片阅读模式。

## V2.6 · 四段连贯的卡片学习

回到最初参考的四项学习能力：**词根记词 → 同根词串联 → 释义分组 → 例句与应用**。这不是将旧版所有嵌套卡片直接堆起来，而是以四个连续模块组织词源、词族、意义及句子；四个模块默认全部可见。

- **没有折叠学习卡片**：查词后直接看到拆分、中文解释、可用的历史词形/年代、分组词族、多词性释义、词形变化和例句。不再在快速查词、词源阅读和完整资料之间切换。
- **暖色卡片而非卡片套卡片**：保留紧凑搜索及单词信息，四段采用不同的阅读形式：拆分图、词根连接、分组对照、句子应用。没有营销口号、巨幅品牌图或词频编号。
- **深度资料自动补齐**：现有 26 个字母词典资料包按当前查词自动读取，不用再点“更多”。只取所查字母的包，不预下载全部；失败后基本义项仍可读并可重试。每次读取依然受缓存与超时控制。
- **不制造内容**：未收录的历史不伪造年表，未知同源关系不强行归类，学习例句不标成考试真题。历史来源与许可保留在对应词条。
- **分组清楚**：ced/cess 的成功、继任、前进、接近、让步及先后等语义分支分开呈现，而不是全部当作“成功”。同根词的一小组连接在第 2 段，第 3 段铺开本组全部词条及其含义。
- **连贯但不强迫**：小题直接可见，但无答题门槛；所有三个推荐方向直接展示，四词路线仍有明确终点，浏览不计作掌握。
- **其他页面也不折叠**：词族路线、学习范围、复习安排、统计、离线资料和隐私说明直接展示为开放区域。词根大全仍采用分页（不一次渲染 600 多主题）。
- **数据完整保留**：49,426 词条、335 个精选词源资料、643 词根/词缀主题、全部例句及旧学习记录保留。V2.5 缓存中的完整词典资料包会迁入 V2.6。

当前发布检查：`python3 tests/check_v26.py`、`node tests/check_memory_v2.cjs`。隔离浏览器中的当前 UI 回归：`CDP_PORT=9256 node tests/browser_cards_v26.cjs`。该浏览器测试会重置隔离站点测试存储，不能连接个人浏览器配置。旧版 `browser_minimal_v25.cjs` / `check_v25.py` 描述的是已被本次设计替代的折叠界面，不再作为当前 UI 验收标准。

## V2.4 · 查词与短路线阅读体验

- 默认提供**快速查词**：中文义项、发音、例句、收藏及复习入口；不强迫用户做题或阅读长文。
- 切换到**顺着词源读**：当前词的问题引导、简洁中文解释、折叠历史资料、一道可跳过的小题、最多三个有明确理由的后续词。
- 首批 15 个独立撰写的深读卡片，其中 8 个普通词（resilient、resilience、asset、equity、underwrite、mortgage、company、capital）新增中文词源短文和原创双语例句。资料逐词提供来源；其他词沿用既有词源、构词或字典内容，不声称所有 49,426 个词都有同等丰富的历史故事。
- 4 条有限的四词路线：让步与权利、摄影词族、过程与程序、商业场景。读完后有结束页，浏览记录不会被算作掌握。
- 保留查词路径、返回时恢复阅读位置、继续上次阅读。本机保存浏览/展开/路线/题目首答记录；前台活跃时长会排除隐藏、失焦和长时间未操作的页面。该计时是估算，不证明注意力或记忆效果。没有外部统计 SDK。
- 原有收藏和自适应复习仍使用原存储键；V2 JSON 备份新增可选 reader 字段，向后兼容。阅读记录也可单独导出/清空。
- **加载优化**：原词典和例句两个首屏资源合计未压缩 11,002,746 字节，改为 4,551,348 字节的基本词库脚本，下降 58.6%。这是资源原始体积，不是网络耗时或阅读留存的实测提升。
- 完整英文义项、词形及开放例句分为 26 个字母资料包，点击“完整词典资料”时才加载。基础中文释义及精选资料仍可离线；已打开的扩展资料自动缓存。“我的”可选择完整下载（约 11 MB）或中止，已有缓存保留。原始全部资料可无损还原。
- 深链接示例：?word=resilient&mode=explore。手机和电脑都能打开，无需会员、登录或付款。

## 准确性与局限

词根构词拆解是学习辅助，不是严格的历史语言学逐词考证。来源示例关联不等于完整词源证明。考试级别标签为词表参考，不代表官方考纲。没有开放例句的普通词条不伪造真实例句。本网站没有复制任何商业词典的付费会员内容。

## 个人信息

浏览器本地保存收藏、复习计划、错题、历史查询，沿用旧版存储键，可导入原 JSON 备份。无需登录、会员或支付，也不将学习记录自动上传服务器。首次在线载入需下载并缓存较大的开放词库，以后可离线查词；联网查词功能仍依赖网络。

运行本地预览：python3 -m http.server 8000，然后打开 http://localhost:8000/ 。
