# 词根实验室 / Root Lab

免费词根查词与英语记忆工具。部署在 GitHub Pages：<https://zwphhxx.github.io/wordroot-lab/>

## 功能（2026-10 V1.1）

- 无需会员或注册，打开首页直接查词；本地收录 **37 组词根、335 个不同单词**（343 条词根关联记录）。
- 英文、中文释义、词根搜索；拼写相近推荐、简单英语词形还原、最近查询。
- 未收录的英文词可调用 [Free Dictionary API](https://dictionaryapi.dev/) 在线查询英语词义、词性、音标，提供 [剑桥英汉词典](https://dictionary.cambridge.org/dictionary/english-chinese-simplified/) 跳转查看中文解释；断网或 API 失败时显示错误说明，不冒充本地核验词条。
- 词根、词源与双语原创例句；已收录词可按需联网查询音标。
- 收藏、CSV/JSON 导出、练习记录、简化间隔复习。
- 四类测验：英译中、中译英、拼写回忆、例句填空；答错自动计入错题与复习。
- 支持 PWA 主屏幕安装以及内置词库的离线使用。

## 重要说明

- 考试等级标签是**学习参考**，未完成与官方考纲逐项核验；新增词条暂不赋考试等级。
- 词根分解用于教学记忆，可能与严格历史语言学意义上的构词结构存在区别。
- 离线仅支持内置词根词库和复习；联网查词与音标查询需要网络。联网查询时，所输入的英文单词会发送至第三方词典 API。
- 浏览器本地存储保存最近查询、收藏、复习计划、测验进度；**不会因本版本更新被重置**。清除浏览器数据会清掉进度，请使用“我的学习”里的 JSON 备份。
- 提供学习工具功能，不含广告、会员或真实支付。移动端支持直接“添加到主屏幕”。

## 技术结构

无构建步骤的静态站点。主要文件为 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg` 及 PNG 应用图标。GitHub Pages 从 main 分支根目录发布。

## 本地运行

```bash
python3 -m http.server 8000
```

浏览 <http://localhost:8000/>。PWA 要在 HTTPS 或 localhost 下测试。
