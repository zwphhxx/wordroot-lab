# 词根实验室 · 免费英语词典与词根联想（V2.1）

网站：https://zwphhxx.github.io/wordroot-lab/

## 本次扩充

- 49,426 个离线英汉词条；词典中同时收录多条中文释义、英文定义、读音转写、词形变化。
- 606 组开放词根及词缀索引（419 组词根、109 组前缀、78 组后缀），加上原有 37 组精选精讲，共 643 个主题。
- 19,323 个词条匹配到部分英文例句或同义词记录（Princeton WordNet 3.0），与精选词条原有的原创双语例句并存。
- destructive 可以看到 de + struct + ive；antecedent 可以看到 ante + ced + ent。词根关联源于词根例词资料；未能证实的拆分只标记为构词提示。
- 保留免费查词、搜索建议、发音、词根串联、收藏、智能复习、错题强化、每日统计、离线 PWA。
- 手机端词根索引分类为精选精讲、词根大全、常见前缀、常见后缀；长列表分页加载，避免页面阻塞。

## 准确性与局限

词根构词拆解是学习辅助，不是严格的历史语言学逐词考证。来源示例关联不等于完整词源证明。考试级别标签为词表参考，不代表官方考纲。没有开放例句的普通词条不伪造真实例句。本网站没有复制任何商业词典的付费会员内容。

## 文件

- index.html：产品界面与学习逻辑（独立的 JavaScript）。
- lexicon-v21.js：离线词条数据。
- roots-v21.js：词根、前缀、后缀示例及关联索引。
- wordnet-v21.js：开放英文例句和近义词。
- memory-engine-v2.js：智能复习引擎。
- sw.js、manifest.webmanifest、图标：离线 PWA。
- scripts/build_v21.py：重建词库，需要原始许可数据放入本地 .v12-work 目录，此目录不入 Git。
- tests/check_v21.py：数据与发布完整性检查。

## 个人信息

浏览器本地保存收藏、复习计划、错题、历史查询，沿用旧版存储键，可导入原 JSON 备份。无需登录、会员或支付，也不将学习记录自动上传服务器。首次在线载入需下载并缓存较大的开放词库，以后可离线查词；联网查词功能仍依赖网络。
