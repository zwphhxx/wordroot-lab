网站：https://zwphhxx.github.io/wordroot-lab/

## V2.3 · 全部精选单词的词源与构词路径

- 精选词库 **335 个不同单词，全部具有词源资料卡片**（其中 5 个精选词及 2 个常规词保留 V2.2 人工整理的中文历史年表）。
- 其余 **330 个精选词**有独立的词源路径或构词提示：189 条参考历史词形来源、128 条参考构词关系、7 条有词源原文摘要、6 条只有词形学习提示（未附编造的历史年代）。以上来自按单词下载的公开 Wiktionary 结构化资料与精选词库可支持的构词说明。
- 每个来源词条均可打开原始 Wiktionary 页面，遵守 CC BY-SA 4.0；英文摘录在折叠区域显示，单词词根资料与历史语源分开理解。
- 普通离线英汉词典约 49,426 条：已有手工时间线的普通词直接显示中文历史；其他普通词保留 **按需查询开放词源原文** 功能。不能保证每个普通词都有可靠的历史年表。
- 原有词库、收藏、学习记录和智能复习计划不变。数据文件是 word-etymology-curated-v23.js，生成脚本在 scripts/。

## V2.2 · 构词结构与历史词源

- 将**前缀 / 词根 / 后缀**的教学解释与**历史词源及语义演变**分开呈现。
- 为 concession、procedure、antecedent、destructive、success、succeed、succession 增加依据公开词源资料独立整理的中文历史年表及参考链接，修正 concession 的 con- 在该词中可能用于强调，而不是机械地解释为“共同”。
- 所有其他单词可由用户主动点击“查看开放词源原文”，按需调用 Wiktionary API 获取该词的英文 Etymology 小节；网络不可用时保留原始词条链接，不臆造历史信息。
- 公开 API 内容显示时标注 Wiktionary 贡献者及 CC BY-SA 4.0，相关许可和其他语源链接集中在 credits.html。
- 复习算法、本机历史记录、49,426 个离线单词及 643 组词根主题继续保留。中文年表只覆盖已整理的词条，并不声称 49,426 个单词都有完整历史记载。

## V2.1.1：单词解析纠正

- 修复旧版将整组词根的故事、记忆线索直接复制到每个单词的错误。示例：查 procedure 时不再显示 success 的词源故事。
- 为 ced/cess 词族中的 21 个单词加入独立的词源说明与记忆线索，保存在 scripts/curated_word_notes.json 中，供后续编辑与复核。
- 其他精选词根单词则根据正在查询的单词、构词组成及例句生成对应解析，不再错误复用词根示例。
- 词根总览仍展示真正的同根词关联，因此 procedure 的词族中仍会包含 success、proceed 等词。
- 旧版学习记录键和词库、复习、收藏功能保持不变。

## 本次扩充

- 49,426 个离线英汉词条；词典中同时收录多条中文释义、英文定义、读音转写、词形变化。
- 606 组开放词根及词缀索引（419 组词根、109 组前缀、78 组后缀），加上原有 37 组精选精讲，共 643 个主题。
- 19,323 个词条匹配到部分英文例句或同义词记录（Princeton WordNet 3.0），与精选词条原有的原创双语例句并存。
- destructive 可以看到 de + struct + ive；antecedent 可以看到 ante + ced + ent。词根关联源于词根例词资料；未能证实的拆分只标记为构词提示。
- 保留免费查词、搜索建议、发音、词根串联、收藏、智能复习、错题强化、每日统计、离线 PWA。
- 手机端词根索引分类为精选精讲、词根大全、常见前缀、常见后缀；长列表分页加载，避免页面阻塞。

## 准确性与局限

词根构词拆解是学习辅助，不是严格的历史语言学逐词考证。来源示例关联不等于完整词源证明。考试级别标签为词表参考，不代表官方考纲。没有开放例句的普通词条不伪造真实例句。本网站没有复制任何商业词典的付费会员内容。

## 文件

- index.html：产品界面与学习逻辑（独立的 JavaScript）。
- lexicon-v21.js：离线词条数据。
- roots-v21.js：词根、前缀、后缀示例及关联索引。
- wordnet-v21.js：开放英文例句和近义词。
- memory-engine-v2.js：智能复习引擎。
- word-history-v22.js：独立整理的中文词源时间线、前后缀语义及每条历史的公开参考链接。
- history-ui-v22.js：展示历史年表与词根/词缀知识，并在用户主动点击后从 Wiktionary 获取原始英文词源（CC BY-SA 4.0，逐词显示来源），失败时提供词条链接。
- tests/check_v22.py：中文时间线、源链接与缓存完整性回归检查。

- sw.js、manifest.webmanifest、图标：离线 PWA。
- scripts/build_v21.py：重建词库，需要原始许可数据放入本地 .v12-work 目录，此目录不入 Git。
- tests/check_v21.py：数据与发布完整性检查。

## 个人信息

浏览器本地保存收藏、复习计划、错题、历史查询，沿用旧版存储键，可导入原 JSON 备份。无需登录、会员或支付，也不将学习记录自动上传服务器。首次在线载入需下载并缓存较大的开放词库，以后可离线查词；联网查词功能仍依赖网络。

运行本地预览：python3 -m http.server 8000，然后打开 http://localhost:8000/ 。
