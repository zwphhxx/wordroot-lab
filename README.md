# 词根实验室 / Root Lab V2.0

**在线地址：** https://zwphhxx.github.io/wordroot-lab/

免费、无需注册的英语词根学习与英汉查询工具。独立项目，与任何商业词典的付费会员无关。

## V2.0：智能复习与学习仪表盘

- **自适应复习间隔**：在「复习」→「今日复习」中先回忆、显示答案，再选择「忘记 / 困难 / 记住 / 轻松」。系统根据回答更新每个词的复习次数、难度系数、到期日期和遗忘次数。
- **算法说明**：采用透明的 *SM-2-inspired* 简化调度规则，不是 FSRS，没有对个人记忆稳定性进行数据训练，也不保证准确预测遗忘概率。首次「记住」一般安排 1 天后复习；连续记住会逐步延长间隔，答错则缩短。
- **错题强化**：测验与复习中未记住的词会进入错题队列；连续两次明确反馈「记住」或「轻松」后移出待强化队列，历史答错次数仍保留。
- **学习进度统计**：14 天复习活动图、最近记住比例、每日目标（10/20/30 次）、活跃天数、计划中的词和按间隔估计的掌握度（待学习 / 学习中 / 巩固中 / 已掌握）。
- **兼容旧版**：延用 V1.2 的浏览器本地记录键，并自动转换旧版 {step, due, last} 计划而不改变原始到期日期。JSON 备份升级为 V2 格式，继续支持导入 V1/V1.2 的 JSON。
- **完全离线**：13,024 条离线词典、全部学习页面、统计与自适应复习逻辑都可以断网运行。设备之间仍**不自动同步**。
- **免费**：没有会员、真实支付或强制登录。

### 典型流程

1. 查找 success、analysis 等单词并点击「加入复习计划」；
2. 进入「复习」→「今日复习」，选择「开始今日复习」；
3. 先独立回忆中文意思，然后显示答案，按记忆难度打分；
4. 在「学习统计」查看每日目标、最近 14 天趋势和掌握度；在「我的」导出备份文件。

**注意：** 「已掌握」是调度规则给出的学习状态，不是标准化测评结论。「连续学习」只是根据当前浏览器的复习活动估算，不跨设备合并。

## 版本功能

- **13,024 条离线英汉词条**：来自 ECDICT 数据库提取的高频词、参考考试词表及部分词根示例词。支持英文、中文搜索，拼写纠错、简单词形还原和最近查询。不是全量商业词典，未收录词可以主动转为在线查询。
- **37 组精选精讲词根**：335 个不同词（343 条词根与单词关联），具备中文释义、教学拆解、词源线索、词义分组、原创双语例句。
- **41 组附带来源的参考词根**：逐组标注拉丁语／希腊语词源、英文原义，并显示 ECDICT 收录的示例词；与精选词根可交叉跳转。
- **可追溯出处与状态标识**：37 组精选词根中，36 组匹配到参考词根或前缀资料，1 组尚未直接匹配并显示“待核验”。**词根资料匹配≠每个单词的严格历史词源得到验证**。
- **读音与考试标签**：12,266 个词条有 ECDICT 的读音参考标记（部分采用旧式转写，不能一律视为规范 IPA）；6,608 个词条有 ECDICT 考试词表参考标签。标签不代表官方考试大纲认证，用户可以按需联网核对读音。
- **训练与记录**：英译中、中译英、拼写回忆、例句填空、收藏、V2 自适应间隔复习、错题强化、进度可视化及 JSON/CSV 导入导出。旧版浏览器学习记录自动沿用。
- **PWA**：添加到手机主屏幕、离线英汉词典、离线词根及本机学习记录。主动联网查词、在线读音核验需要网络连接。

## 数据范围与来源

原始数据来源 [ECDICT](https://github.com/skywind3000/ECDICT)，本仓库只分发生成的精简词条及词根参考数据。详情见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)，**包括 MIT 许可证全文与快照校验和**。

静态发布文件：

- `index.html` — UI、37 组精选词根及应用逻辑。
- `lexicon-v12.js` — 13,024 条 ECDICT 英汉精简词条。
- `roots-v12.js` — 词根词族关系和来源记录。
- `memory-engine-v2.js` — 自适应复习排程、掌握阶段与每日复习统计计算（纯 JavaScript，可独立测试）。
- `sw.js`, `manifest.webmanifest`, `icon*` — PWA 离线缓存与图标。

**重要限制：** 参考词表标签不等于官方招生考试词表；“词源故事”“词根拆分”是教学辅助，不能替代词典级语源考证。内置读音来自 ECDICT，个别内容可能仍有错误。可靠词典核验入口提供 Etymonline、Cambridge Dictionary 与 Free Dictionary API。

## 隐私与个人数据

无需会员、注册或实际支付。收藏、历史记录、测验、每日统计和复习间隔参数均使用本机浏览器 localStorage；**版本更新不主动清除旧数据**，但清空 Safari 数据、切换设备或隐私浏览可能丢失。可在“我的学习”导出 V2 JSON 备份；导入兼容旧版格式。

仅当用户**主动在线查询**或**主动联网核验音标**时，英文关键词才会发送至 [Free Dictionary API](https://dictionaryapi.dev/)；点击剑桥 / Etymonline 链接将访问对应第三方网站。请遵守第三方网站的隐私政策。

## 本地运行

本项目为纯静态站点，没有服务端和 npm 依赖。

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000/
```

浏览器 PWA 离线测试需要 localhost 或 HTTPS。

## 数据再生成

下载并保存 ECDICT 原始 CSV 和 `wordroot.txt` 到被忽略的 `.v12-work/` 目录；构建脚本会严格检查 `ecdict.csv` 的 SHA-256（见版权声明）。

```bash
python3 scripts/build_v12_data.py
python3 tests/check_v12.py
node tests/check_memory_v2.cjs
python3 tests/check_v20.py
```

构建脚本会刷新 `lexicon-v12.js`、`roots-v12.js` 和 `index.html` 中精选词条的参考考试标签。不会下载非授权数据，也不会自行捏造未收录的单词释义。
