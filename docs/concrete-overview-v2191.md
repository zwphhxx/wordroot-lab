# V2.19.1：让「词义概览」直接显示具体意思

## 原问题
V2.19 的「词义概览」按 `reader-cards` 的主题标题制作预览。对于 `reason`，用户看到「名词 · 动机与目的」「名词 · 表达与交流」「名词 · 思维与知识」「名词 · 状态」「名词用法」等 WordNet 归类，无法直接理解单词的中文意思。

## 新版呈现
- 标题调整为「核心词义速览」，每张预览卡突出**已有词典的实际中文释义**，下方列对应英语原义；词性仅作为小标签。
- 前三项优先覆盖不同语义分组，再补足尚未出现的词性（尤其动词、形容词），其余补充不同含义，总计最多 5 个。
- 对于只有一个主要义项、另有未合并原词库释义的词，保底展示另一条真实记录；不把没有证据的内容强行合并。
- 显示具体中文而非语义分类名；点击直接定位完整义项（原 ID 不变），「查看全部 N 个义项」仍可打开目录。
- 单词 `reason` 5 条文字采用经英语原义及固定词义 ID 双重核对的中文教学短释义，源英文不匹配时自动退回词库原文。仅影响预览层，原始词库字段未改。
- 桌面版 3 列、平板 2 列、窄屏手机 1 列；源完整义项、例句、搭配均不隐藏、不截断。
