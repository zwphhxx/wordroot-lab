# V2.21.0 — 单义项阅读、实用搭配与近义词区别

## 本轮六项交付
1. 顶部改为「单词理解」，默认不以某个百科专门主题代表整个词。reason 用「原因；理由」作为通用入口，概览与义项排序只使用有来源核对的固定义项 ID。未整理的词仍用已有词典记录，不宣称全词库均有语料频率排名。只有配图与当前义项 ID 明确一致且有可用许可信息时才直接显示图片；百科资料移入页末来源区，首次展开才加载。
2. 「更多义项」只展开额外的小选择卡片。详情始终只显示被选中的一个义项，点击选择不会变成全部大标题列表。保留例句、搭配、搜索定位与返回阅读位置的接口。
3. 词形变化为规整的纯文本单元，不再触发查词跳转。
4. reason 新增 14 条独立编写的学习搭配与句型，分为基础句型、说明原因、给出依据、理性与判断、说服与推断五组；默认显示 8 条，支持筛选、更多、展开例句及朗读。带有语法占位符的表达朗读完整英文示例，而不是中文占位符。其他词统一采用紧凑展示和来源保留规则，未凭空补齐固定数量搭配。
5. reason 以 cause、explanation、motive、rationale、excuse 的联系、具体区别及自编对比例句替代默认 WordNet 关系列表。其他词按原义项分组，说明实际存储的概念关系方向，不声称上位/下位词就是可互换同义词。移除每卡重复的分类、通用警告和机译徽标。
6. 普通查词页删除「接着认识一个词」，不重复推荐关联词。正在进行的学习路线仍保留该流程的下一词按钮。

## 文字来源与范围
学习说明、中文概括和例句为独立编写，不复制学习词典的完整词条，也不标注为维基百科引文。可核对的主要参考保存在 learning-notes-v221.js，且可从页面「资料与来源」访问。

- Cambridge English Grammar Today：Reason，for + noun / doing 与 to + infinitive。
- Oxford Advanced Learner's Dictionary：reason noun，基本词义、搭配和相近词。
- Cambridge：reason with、rationale、cause。
- Longman Dictionary：reason something out。

词典包、原始语义关联、翻译来源、图片署名/许可均保留。隐藏重复机译徽标不代表所有译文经过人工校订；来源区统一说明翻译状态。
