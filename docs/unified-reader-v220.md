# V2.20.0 — 一个义项、一个阅读入口

按照最后确认的「Analysis output 1」合并版线框图实现，不采用中间仍有独立详情／例句模块的旧图。

## 阅读结构

页面依次呈现单词、百科词解、核心词义速览、词形变化、常用搭配、必要的构词与来历、相关词与区别及已有语境练习。目录只列实际存在的主要章节；桌面为侧边目录，窄屏为页面内目录。词义展开不再打开对话框。

核心词义速览包含完整释义。默认展示不超过五个义项选择入口，选中后就在同一张卡片内显示对应释义、例句与搭配。「展开全部」在本模块内显示所有义项子卡片，点击各条标题可展开全文。不再在页面下方重复设置「具体词义」或例句索引模块。原来的独立例句列表已移除；没有确切义项绑定的例句保留在核心模块内的「通用例句」中，不强行猜测归属。

例句朗读按钮位于各句右上侧，和该句绑定；删去正文中反复占行的例句来源、机器翻译标签，将这些信息收纳在可展开的来源说明里。搜索索引与例句使用同一套经来源 ID 和原英文核对的显示译文，不再出现详情修正而索引仍显示旧译文的情况。

## 义项与来源边界

不修改原始词典。普通词典义项、经过核验的独立含义，以及绑定了例句或搭配的原词库义项，均保留在统一的义项列表中。未核验是否重复的原词库概括性释义不再显示为额外编号卡片，原文仍可通过同一区域内简短的「词典来源对照」查看。只有原词库资料的单词依然保留正常的主要义项。

以 reason 为例，正文保留九个具体义项；另三条原词库概括性释义移入来源信息，不再将它们算作第十至第十二个学习义项。核心入口顺序是展示策略，不是基于语料频率计算的常用度排名。

全量检查发现四个词条存在重复的原词库 ID：crowley、gardiner、hoskins、walcott。仅在 ID、中文、英文和词性均相同的情况下合并显示，保留来源 ID；发现同 ID 内容冲突时拒绝静默合并。

## 其他模块

词形变化按原形、复数、过去式、过去分词、现在分词、第三人称单数、比较级、最高级的固定顺序排列。只显示已有词形，不编造缺失变化；桌面等宽表格，手机规则网格。

相关词按原词典给出的上位／下位等义项关系呈现，并明确「关联到本词的哪个义项」。不把这些关系宣传为所有语境通用的同义词。紧凑卡片可跳转至关联词，保留源义项和目标义项 ID。

百科图片和中英文本一起置顶，不再把图片拆到上方、正文留在底部。已有可靠词义主题关联时使用该主题；没有可靠关联时保留明确的主题选择，不用生成的占位图冒充维基百科配图，也不宣称所有单词都有配套百科。

reason 的英语 Reason 与中文「理智」通过 Wikidata Q178354 核验为同一对象。本地保存真实来源的短摘要和 Commons 公有领域插图，明确此主题解释「理智／推理能力」，并不覆盖 reason 的全部字典义项。图片与文本完整署名见 THIRD_PARTY_NOTICES.md。中英文为独立语言条目的摘要，不是逐句翻译。
