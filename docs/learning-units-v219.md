# V2.19.0 — 义项、例句与搭配的一体化阅读

## 本次交付
- 每个有证据支持的词义及其对应例句、搭配呈现在同一个学习单元；每张物理卡片只包含一个词义，逻辑主题标题只显示一次，相关卡片视觉连续。
- 例句只能根据唯一有效的原义项 ID 归属；搭配只能依据现有明确或人工复核的词头义项对应关系归属。不能证明关联的记录保留在「其他搭配／其他例句」，不生成、猜测或删除解释。
- 首页加入最多五个主题入口、「全部义项目录」以及本词内的中英搜索；点击搜索结果和目录均定位到原始义项、例句或搭配。
- 新增「义项／搭配／练习」快捷导航（无该词的测试题时链接至既有复习模块）。不折叠、不截断、不改变词库及学习记录。
- 新增脚本、样式和 Service Worker 缓存版本 V2.19.0；保留 V2.18 资源与词库数据，支持旧缓存升级。
