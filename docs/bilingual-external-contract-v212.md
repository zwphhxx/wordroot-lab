# V2.12 外部来源显示契约：保留来源，不展示伪造对照

依据：用户后来明确要求中英词典的学习内容均为中英文对照。这优先于 V2.11 曾允许“没有中文就直接展示英文摘要”的旧行为。

## 两个不可同时满足的旧断言

1. `English-only source is not fabricated into Chinese` 原断言同时要求：页面显示英文百科正文、没有中文正文、提示暂缺中文。
2. `Article survives same-word repaint` 原断言通过查找英文正文判断请求结果是否丢失；测试数据没有任何中文对应。

新版仍保留“不伪造翻译”和“重绘不丢结果”这两个目标，但未配对正文不应冒充已完成的双语学习材料。原始 API 内容继续留在来源缓存中，页面给出对应词条链接，并保留图片及双语状态说明。缺失语言必须进入审计记录，不能计入已完成覆盖。

## 替代测试必须更严格

`tests/browser_external_bilingual_v212.cjs` 同时检查：

- 真正非空的中英正文同时显示，且声明是同主题独立摘要、非逐句翻译。
- 两种语言的来源都可访问，不把不同实体的条目拼成一对。
- 没有中文时，不编造中文、不将单独英文塞入学习摘要。
- 原始英文字符串在来源缓存中保留，原始链接仍存在；缺失状态计数不是成功。
- 已完成的双语结果、尚缺对应语种的结果，在异步请求期间发生同词重绘后都保留正确来源身份。
- 旧词的迟到结果不能覆盖新查的词。
- 不新增折叠卡片。

原测试文件保持不变；原运行日志和失败记录另存。只有原失败严格限定为上述两处、其他旧断言均通过，且替代测试针对同一构建和当前代码全部通过，才可在新契约下认定旧功能回归通过。

这不是整体外部内容双语验收通过：图片在线候选、未知词词源原文、尚缺语种的主题等仍要单独审计。`reports/external-content-pair-audit.json` 未覆盖的项目必须继续阻断正式发布。
