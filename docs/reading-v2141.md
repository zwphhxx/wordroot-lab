# V2.14.1 路线完成状态修复

V2.14统一阅读主线保持不变。复测发现同词资料异步返回可能将路线完成页替换为词条正文，阻断保存整组和返回操作。

本补丁保持独立的完成页面状态；仅显式查新词、重开词条或返回首页时退出，并使旧加载轮次失效。保存已在复习计划中的词不改变其原复习日期。

使用reader-v2141.js和navigation-v2141.js的版本化资源，保留原文件，避免旧Service Worker将旧脚本与新页面混用。

验证：完成状态11项、阅读26项、深层组合27项；全库49,426词及3,662包保全检查，复习算法11项和读取组件10项均通过。发布后的公网验证独立记录。词典译文未重新审核。
