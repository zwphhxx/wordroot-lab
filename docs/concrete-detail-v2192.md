# V2.19.2 — 「用法」详情页改为具体词义阅读

## 修复的问题
V2.19.1 已让首页词义概览显示可理解的含义，但「用法 / Usage」仍在各组顶部和每张义项卡片重复展示 WordNet 抽象分类（例如「名词 · 动机与目的」）、在标题和释义行重复中英文原句，并在例句已直接出现时仍显示「看对应例句」。例句还重复显示相同 WordNet 分类标题，造成较大认知负担。

## 本次修改
- 每条义项卡片统一按「编号与词性 → 实际中文词义 → 必要时一句通俗说明 → 原始双语释义 → 内嵌例句与搭配」呈现。
- 词义短标题与 V2.19.1 概览使用同一个由唯一义项 ID 与英语原义校验的显示函数。对于已有短标题的义项，不再同时将原始英语解释放在标题旁；若原始中文恰好就是标题，则只展示一次，不额外生成同文标题。
- 原始中英释义与机器翻译来源标记完整保留，但显示层级降低；读者可区分经过核验的教学用短释义和原词典机译文本。
- 「用法」章节及全部义项目录不再展示「名词 · 动机与目的」等抽象 WordNet 分类标题；每项目录链接直接指向具体词义。
- 去掉已经有内嵌例句时的「看对应例句」跳转，以及例句前重复的类别标题；保留全部例句、朗读和译文。
- 对 `reason` 的 5 条确有误译的例句作显示层人工校订，包括 `the reason that war was declared`、`We reasoned that…`，以及一句把「诉诸理性／激发情绪」关系译反的例句。校订仅在原词条、来源 ID 与原英文逐字匹配时生效，不改动原始词库包。
- 词义来源归属、卡片 ID、文章导航、收藏、复习、离线缓存及导入导出数据结构均不变。
